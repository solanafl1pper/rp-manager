# RP Manager (Resource Pack Presets)

Мод для Minecraft (**Fabric / Quilt / NeoForge / Forge**), который добавляет полноценную систему заготовок (пресетов) ресурспаков прямо в стандартное меню выбора ресурспаков!

---

## Основные возможности

- **Заготовки прямо в меню ресурспаков:**
  Все созданные заготовки отображаются в меню со специальной фирменной иконкой, золотым выделением и количеством паков.
- **Применение в 1 клик:**
  Достаточно нажать «Применить» на заготовке — мод автоматически выгрузит лишние паки и загрузит все нужные в точно заданном порядке!
- **Создание и редактирование заготовок прямо из игры:**
  Кнопка **«✦»** внизу экрана ресурспаков открывает удобное меню:
  - Выбор паков из списка с реальными иконками (`pack.png`).
  - Поиск и постраничная навигация.
  - Быстрое сохранение активного набора в 1 клик.
- **Адаптивный интерфейс под любое разрешение:**
  Кнопки аккуратно выравниваются по нижней панели на любых мониторах и GUI Scale — вплоть до 4K.
- **Быстрый доступ к файлам:**
  Кнопка **«📁»** в один клик открывает папку `.minecraft/resourcepack_presets/` в проводнике.
- **Предупреждение о недостающих паках:**
  Если какой-то ресурспак из заготовки не найден на компьютере, мод загрузит все доступные и покажет уведомление (Toast) со списком недостающих.
- **Клиентский мод:**
  Работает на любых серверах без необходимости установки на сервер.

## Сборка из исходников

```bash
git clone https://github.com/solanafl1pper/rp-manager.git
cd rp-manager
./gradlew build
```

Готовые JAR-файлы для всех версий появятся в:
- `rp-manager-1.21.1/build/libs/`
- `rp-manager-1.20.1/build/libs/`
- `rp-manager-1.19.2/build/libs/`
- `rp-manager-1.18.2/build/libs/`
- `rp-manager-1.16.5/build/libs/`
