# RP Manager (Resource Pack Presets) 🎨

Мод для Minecraft (**Fabric 1.20.x** и **1.21.x**), который добавляет полноценную систему заготовок (пресетов) ресурспаков прямо в стандартное меню выбора ресурспаков!

---

## 🌟 Основные возможности

- **Заготовки прямо в списке доступных ресурспаков:**  
  Все созданные заготовки отображаются в верхней части левого списка («Доступные ресурспаки») со специальной фирменной иконкой, золотым выделением и количеством паков.
- **Применение в 1 клик или перетягиванием:**  
  Достаточно нажать стрелочку `>` на заготовке или перетянуть её вправо — мод автоматически выгрузит лишние паки и загрузит все нужные в точно заданном порядке!
- **Создание заготовок прямо из игры:**  
  Кнопка **«✦ Создать заготовку»** в меню ресурспаков открывает удобное окно, где можно задать имя новой заготовки для текущего набора активных паков.
- **Быстрый доступ к файлам:**  
  Кнопка **«Папка заготовок»** в один клик открывает папку `.minecraft/resourcepack_presets/` в проводнике Windows — легко копировать, бэкапить и передавать заготовки друзьям.
- **Предупреждение о недостающих паках:**  
  Если какой-то ресурспак из заготовки не найден на компьютере, мод загрузит все доступные и покажет уведомление (Toast) со списком недостающих.
- **Удаление в 1 клик:**  
  На каждой заготовке в правом углу есть кнопка `[✕]` с диалогом подтверждения удаления.

## 📦 Поддерживаемые версии

| Версия Minecraft | Загрузчик | Файл мода |
|---|---|---|
| **1.20.1** (1.20.x) | Fabric | `rp-manager-fabric-1.20.1-*.jar` |
| **1.21.1** (1.21.x) | Fabric | `rp-manager-fabric-1.21.1-*.jar` |

*Требуется установленный Fabric Loader и Fabric API.*

---

## 🛠 Сборка из исходников

```bash
git clone https://github.com/solanafl1pper/rp-manager.git
cd rp-manager
./gradlew build
```

Готовые JAR-файлы для обеих версий появятся в:
- `rp-manager-1.20.1/build/libs/`
- `rp-manager-1.21.1/build/libs/`
